# Security

Ironrein is a hackathon project. It runs on NEAR testnet only, has not been audited, and should not hold real funds.

The threat model, including what is not defended, is in [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md), and the known limits are in the README.

To report a problem, open a [GitHub issue](https://github.com/prembharne/ironrein/issues). For something sensitive, use GitHub's "Report a vulnerability" option on the Security tab. Never post private keys or seed phrases.
